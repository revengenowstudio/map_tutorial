# Level 1 入门
## 1.2 将触发关联到物体

触发里有许多条件和结果依赖具体的某个东西，这时候就需要「关联」——把触发绑定到指定的东西上。

### 1.2.1 关联地图上的科技类型

> 习惯上把游戏里的兵、坦、机、建称为“科技类型”，就是对玩家而言有实感的操作对象。

首先直接给出操作方法：**双击地图上的科技类型，在“关联标签”里选中你写的触发，并确定。**

然后举一个最简单的例子：`结果14 - 更改对象所属`，要给玩家~~辣个玩意~~<u>科技前哨站</u>。  
在熟悉了触发编辑器之后，你应当能根据下面的约束简单地手搓一个触发（括号内为参数，下同）：
```
名称：change neutral ownership
触发所属：任意
重复类型：0 - 任一满足，单次触发
关联触发：无
简 √ 中 √ 难 √ 禁止 ×

条件：13 流逝时间(10)
结果：14 更改对象所属(玩家所属方)
```
> 玩家所属方可以在**编辑→所属方**查看，日牛里描述为“人类玩家参战方”。

在地图里预先摆出辣个玩意儿。写完这个触发后，双击它，**在“关联标签”里选中你刚写的触发**，并确定。  
这样就绑好了（

### 1.2.2 关联单元标记

前面 1.1 提到过，有些触发会判定「区域」，需要你把触发“放置”在地图上。实际上触发是根据**单元标记**做的判定。

> 单元标记简单来说就是**给地图划一块地**，让触发判定有什么能移动的东西踏进了这块地，仅此而已。

操作方法：**在触发编辑器里按下“放置于地图”，按住鼠标，在地图上画出这个「区域」（可以是空心的）**。

还是举例：`条件1 - 进入事件`，玩家的坦克踏过某条线，即刻让它爆炸。

```
名称：tank boom
触发所属：任意
重复类型：任一满足，单次触发
关联触发：无
简 √ 中 √ 难 √ 禁止 ×

条件：1 进入事件(玩家所属方)
结果：32 摧毁关联对象
```

在地图上放一辆玩家的灰熊，然后按照 [1.2.1](#121-关联地图上的科技类型) 的方法给灰熊挂上这个触发。  
然后触发编辑器里~~选定`tank boom`为当前触发~~，按下“放置于地图”，按住鼠标，在地图上画出一条线（不要过坦克所在的单元格）。
这样「区域」也关联好了（虽然只是一条线（
